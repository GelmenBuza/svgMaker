# Roadmap новых фич для svgMaker

## P0 — Core UX (что даст максимальный эффект сразу)

- **История изменений (Undo/Redo + Timeline)**
  - Почему: для SVG-редактора это базовая функция, без нее сложно работать с экспериментами.
  - Что добавить: стек snapshot/patch, hotkeys `Ctrl/Cmd+Z`, `Ctrl/Cmd+Shift+Z`, панель истории.

- **Autosave с защитой от гонок**
  - Почему: сейчас есть риск конфликтов между частыми изменениями и записью версий.
  - Что добавить: debounce 500-800ms, очередь из одного активного запроса, `flush` перед уходом со страницы.

- **Импорт/экспорт**
  - Почему: нужен полноценный обмен файлами между пользователями и проектами.
  - Что добавить: `Export SVG`, `Export JSON (editable format)`, `Import SVG/JSON` с валидацией.

- **Панель слоев (Layers)**
  - Почему: упрощает работу с множеством path.
  - Что добавить: reorder (drag-n-drop), hide/show, lock/unlock, duplicate, rename layer.

## P1 — Совместная работа и командный сценарий

- **Проектные комнаты в чате**
  - Что добавить: чат по `projectId`, presence (кто онлайн), системные события редактора.

- **Шеринг проекта по ссылке**
  - Что добавить: `viewer`/`editor` роли, одноразовые invite links, revoke доступа.

- **Комментарии на canvas**
  - Что добавить: pin-комментарии на координатах, mention пользователя, статус `resolved`.

## P2 — Точность и профессиональные инструменты

- **Grid / Snap / Guides**
  - Что добавить: шаг сетки, магнит к узлам/направляющим, отображение координат/углов.

- **Булевы операции над path**
  - Что добавить: union/intersect/subtract/exclude для нескольких контуров.

- **Расширенные трансформации**
  - Что добавить: выравнивание, distribute, numeric transform panel (x/y/scale/rotate/skew).

## P3 — Продуктовые и монетизационные идеи

- **Template Gallery**
  - Что добавить: публичные шаблоны, теги, поиск, кнопка `Use template`.

- **Version compare**
  - Что добавить: визуальный diff между версиями, откат до выбранной версии.

- **Экспорт пресетов**
  - Что добавить: пресеты для `Figma`, `React component`, `Icon sprite`, `Lottie prep`.

## Технические фичи (в параллель с roadmap)

- **Тесты и CI**
  - Unit: `parsePathData`, `pointsArrToString`, transform utils.
  - Integration: auth + projects API.
  - CI: lint + build + tests на каждый PR.

- **Наблюдаемость**
  - Что добавить: централизованный logger, client error tracking, метрики по autosave/ошибкам.

- **Feature flags**
  - Что добавить: включение экспериментальных фич без полного деплоя.

## Быстрый план внедрения
1. Закрыть P0 (Undo/Redo, autosave queue, import/export).
2. Добавить Layers + Grid/Snap (самый заметный рост UX).
3. Начать collaborative блок (project chat + sharing links).
4. После стабилизации: Template Gallery и version compare.
